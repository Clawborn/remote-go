# Remote Go

用 Chromecast Remote 给 Codex 口述想法和修改要求，检查执行结果，再继续迭代。做网页时，可用同一个遥控器切换、刷新和标注预览。

## 第一次使用

1. 打开 Remote Go。配对成功时，窗口会显示 **Chromecast Remote 已连接**。按一下最上方大圆环正中的小圆钮（确定键），查看左下角的 **最近按键**。
2. 在「当前预设」选择 **Agent Coding**，再打开 **启用改键**。在 macOS「隐私与安全性」的「辅助功能」里启用 Remote Go，让它能发出快捷键。如果连接正常但收不到按键，可从窗口底部的权限入口检查「输入监控」，授权后退出并重新打开 Remote Go。
3. 如有提示，允许 Remote Go 访问蓝牙。看到 **语音键已连接** 后，试按一次专用语音键，确认「语音键信号」显示收到事件。
4. 在 Codex 的内置浏览器打开本地开发地址，例如 `http://localhost:3000`。网站由你的开发服务器提供，遥控器通过 Codex 切换布局、刷新和标注。

## 用专用语音键触发微信语音输入法

专用语音键是大圆环下方第一排右侧带圆点的深色按钮。预设把这颗键映射为全局 Fn。程序从遥控器独立的 ATVV 蓝牙控制通道读取按下和松开，以保留双击和长按时长。

在任意输入框中快速短按两次，或按住说话再松开。微信语音输入法会按它的现有设置处理，收音使用它当前选择的麦克风。Remote Go 发送 Fn 之前需要 macOS「辅助功能」授权。如果升级后系统开关已打开，软件仍提示需要授权，请在系统设置中移除旧版 Remote Go 条目，添加当前的应用文件，再退出并重新打开 Remote Go。

## 在遥控器图上改键

点正面图上的实体键，在右侧选择动作。选「键盘快捷键」后，可以录入单键或组合键。清除映射后，可继续从图上重新配置。改动即时保存到当前预设。

映射为键盘键或组合键时，短按发送一次，长按按 Mac 的键盘设置连发，松手停止。比如映射为 Delete 后，按住会连续删除光标左边的字符。

图上覆盖全部 15 个键，包括方向环、确定、语音、返回、主页、静音、音量加减、YouTube、Netflix、电源和信源。音量加减的点击区域标在遥控器右侧。点击「学习按键」后，也可按一下实体键来定位。蓝牙能上报的键才会执行 Mac 上的映射。电源、信源、静音和音量如果只向电视发红外信号，遥控器图仍可编辑，但 Mac 收不到按键。

## 切换和保存整套按键

- **Agent Coding** 接续之前已保存的按键。方向环直接发出键盘的 ↑、↓、←、→，可在不同应用里使用。
- **看视频** 把确定键设成空格、返回设成 Esc，方向键用来移动，侧键和静音键控制 Mac 的系统音量。
- **保存** 保存当前预设的整套映射，界面会显示保存确认。改键时也会自动保存。
- **另存为…** 复制当前的整套映射，输入名称后切到新预设。在新预设改键，原方案里的映射会保留。
- **管理预设** 可以新建空白方案，也可以重命名或删除自定义预设。每次切换和改键都保存在本机。
- **长按主页键** 约半秒，默认在 **Agent Coding** 和 **看视频** 之间切换。屏幕顶部短暂显示当前预设，继续使用原来的窗口。点遥控器图上的「主页」可关闭长按，或指定任意两套已保存的预设。短按执行当前预设给主页键设定的动作。

## 按应用改键

在右侧「按应用改键」里选 Codex、Claude、Grok Bot、WorkBuddy 或豆包工作，再点遥控器图上的按键并选择动作。也可以点「添加应用…」选择其他已安装的 App。软件按当前前台 App 自动使用对应映射。只有单独改过的键会覆盖预设里的默认映射。用「恢复默认」撤销覆盖，用「停用按键」让这个键在当前 App 里不执行动作。应用映射随整套预设保存和复制。

## 用信源键切换应用

在 Agent Coding 和看视频的默认映射里，短按遥控器正面右下角的「信源」键会列出 Mac 正在运行的 App。用方向键选中一个，按圆环中间的确定键打开。按返回或再短按一次信源键关闭。也可以把「切换应用」赋给其他遥控器键。

## 飞鼠模式

在 Remote Go 主窗口顶部打开「飞鼠模式」，或按住右下角的信源键 1 秒。开启时屏幕显示「飞鼠模式」。短按方向键微调 Mac 指针，按住加速，松手停止。确定做一次左键点按。侧边音量加减短按滚动一格，按住连续滚动，松手停止。按返回或再次按住信源 1 秒退出，短按信源会退出飞鼠模式并打开应用列表。退出时，屏幕会短暂显示「飞鼠已退出」，提示条随即散成细小粒子。开启系统「减少动态效果」时只显示文字提示。

在看视频预设中，侧边音量加减按住可连续调节 Mac 音量。

支持把「切换飞鼠模式」分配给其他可识别的按键。窗口顶部可直接开关。

## Agent Coding 预设

短按主页轮换最近三个 Codex 会话。在 Codex 前台时，侧边音量＋往左栏上一项，音量−往下一项。沿左栏的已展开列表移动，到首尾停止。Remote Go 在启用改键时记录能够识别到的最近打开的 Codex 本地会话，只保存会话 ID。记录不足时使用 Codex 的三个最近更新会话位。切换后会尝试聚焦输入框，供圆点语音键继续触发微信听写。

在 Codex 前台按住音量＋ 1 秒，会看到当前登录 Codex CLI 账户的剩余用量和重置时间。用量浮层几秒后自动关闭，当前对话保留焦点。

在 Grok Bot 前台，短按音量＋切到左栏上一项，音量−切到下一项，到首尾停止。切换后会尝试聚焦输入框。可以在「按应用改键」中选 Grok Bot 改这两个键。

如需在不同 Agent 之间快速切换，可把空闲键映射为「轮换 Codex 和 Claude」，它会尝试聚焦目标 App 的当前会话。信源键的 App 列表也可以切到 WorkBuddy 和豆包工作。

| 遥控器按键 | 动作 |
| --- | --- |
| 主页 | 短按轮换最近三个 Codex 会话并尝试聚焦输入框，长按切换预设 |
| 音量 + | 短按到左栏上一项，按住 1 秒查看 Codex 用量 |
| 音量 − | Codex 左栏下一项 |
| 静音 | 切换网页标注模式（⌘⇧.） |
| ↑／↓／←／→ | 对应的键盘方向键 |
| 选择会话（可映射给任意键） | 在 Codex 或 Claude 里打开会话选择，在选择框里再按一次关闭 |
| YouTube | 打开 Codex 并聚焦对话输入框 |
| Netflix | 打开 Claude 桌面版并聚焦对话输入框 |
| 专用语音键（圆点图标） | 全局 Fn |
| 确定 | 当前配置发送 Return，可用于 Codex 和 Claude |
| 信源 | 切换 Mac 上正在运行的应用 |
| 电源 | 在图上单独配置 |

会话选择打开后，用方向上／下移动，按确定进入选中的对话。会话选择只在支持的应用里生效。

关闭窗口后可从菜单栏重新打开。暂停改键或退出软件会释放遥控器。改键启用期间，未配置的蓝牙按键会暂停。

## 语音和验证

已测试的 Chromecast Remote 通过 BLE HID 上报按键，麦克风通过独立蓝牙通道传输。启用 Fn 映射时，程序只用 ATVV 控制通知判断语音键的按下和松开，微信输入法负责录音和听写。关闭改键后，可以单独试用软件内置的遥控器麦克风转写。

已开发期间已在实体遥控器上验证方向键、确定和专用语音键。程序自检覆盖 HID 报告、主页键短按和长按、预设保存、Fn 按下与松开、ATVV 能力和 ADPCM 解码。可用 YouTube 和 Netflix 实测是否把光标移到对话框，再试微信输入法的双击和长按听写。

## 重建和升级

在仓库根目录运行 `./build.sh`，输出到 `dist/Remote Go.app`。从同一位置重新安装或更新后，如果改键失效，可以在系统设置检查辅助功能授权。
