# Remote Go

用 Chromecast Remote 给 Codex 口述想法和修改要求，检查执行结果，再继续迭代。做网页时，可用同一个遥控器切换、刷新和标注预览。

## 第一次使用

1. 打开 Remote Go。配对成功时，窗口会显示 **Chromecast Remote 已连接**。按一下最上方大圆环正中的小圆钮（确定键），查看左下角的 **最近按键**。
2. 在「当前预设」选择 **Agent Coding**，再打开 **启用改键**。在 macOS「隐私与安全性」的「辅助功能」里启用 Remote Go，让它能发出快捷键。如果连接正常但收不到按键，可从窗口底部的权限入口检查「输入监控」，授权后退出并重新打开 Remote Go。
3. 如有提示，允许 Remote Go 访问蓝牙。看到 **语音键已连接** 后，试按一次专用语音键，确认「语音键信号」显示收到事件。
4. 在 Codex 的内置浏览器打开本地开发地址，例如 `http://localhost:3000`。网站由你的开发服务器提供，遥控器通过 Codex 切换布局、刷新和标注。

## 用专用语音键听写

专用语音键是大圆环下方第一排右侧带圆点的深色按钮。安装 [Remote Go Mic](../Driver/RemoteGoMic/README.md) 后，在 Remote Go 和听写软件里都把麦克风选为 **Remote Go Mic**。

在豆包输入法里，可用 **Fn** 作为长按快捷键，用 **Fn＋左 Control** 作为免按快捷键。打开 Remote Go 的语音键设置，录入同一组快捷键。按住语音键说话，松开结束。勾选「双击语音键」后，快速按两下进入持续听写，再按一下结束。

## 在遥控器图上改键

点正面图上的实体键，在右侧选择动作。选「键盘快捷键」后，可以录入单键或组合键。清除映射后，可继续从图上重新配置。改动即时保存到当前预设。

映射为键盘键或组合键时，短按发送一次，长按按 Mac 的键盘设置连发，松手停止。比如映射为 Delete 后，按住会连续删除光标左边的字符。

图上覆盖全部 15 个键，包括方向环、确定、语音、返回、主页、静音、音量加减、YouTube、Netflix、电源和信源。音量加减的点击区域标在遥控器右侧。点击「学习按键」后，也可按一下实体键来定位。蓝牙能上报的键才会执行 Mac 上的映射。电源、信源、静音和音量如果只向电视发红外信号，遥控器图仍可编辑，但 Mac 收不到按键。

## 切换和保存整套按键

- **Agent Coding** 接续之前已保存的按键。方向环直接发出键盘的 ↑、↓、←、→，可在不同应用里使用。
- **看视频** 预设针对 YouTube。确定键播放或暂停，主页短按全屏，左右键快退／快进，侧边音量键和静音键控制 Mac 的系统音量。
- **保存** 保存当前预设的整套映射，界面会显示保存确认。改键时也会自动保存。
- **另存为…** 复制当前的整套映射，输入名称后切到新预设。在新预设改键，原方案里的映射会保留。
- **管理预设** 可以新建空白方案，也可以重命名或删除自定义预设。每次切换和改键都保存在本机。
- **长按主页键** 约半秒，默认在 **Agent Coding** 和 **看视频** 之间切换。屏幕顶部短暂显示当前预设，继续使用原来的窗口。点遥控器图上的「主页」可关闭长按，或指定任意两套已保存的预设。短按执行当前预设给主页键设定的动作。

## 共享社区预设

1. 选中要分享的预设，点「管理预设 → 导出当前预设…」，保存 `.remote-go.json` 文件。文件包含这一套默认映射和按应用覆盖，可上传到社区或通过文件分享。
2. 收到其他人分享的文件后，点「管理预设 → 导入预设…」，选择 JSON 文件。核对预览中的按键和应用覆盖后，点「导入预设」。
3. 从「当前预设」列表选中导入的方案开始使用。重名时会自动加编号。

文件格式使用 `format: "remote-go-preset"` 和版本 `1`。建议社区作者先在 Remote Go 里配好按键再导出，这样上传的文件可以直接导入。格式只包含预设名称与按键映射、应用覆盖及对应应用的名称。

## 界面语言

点主窗口右上角的语言按钮即可切换。中文界面显示「English」，英文界面显示「简体中文」。界面会立即切换并保存选择。

## 按应用改键

在右侧「按应用改键」里选 Codex、Claude、Grok Bot、WorkBuddy 或豆包工作，再点遥控器图上的按键并选择动作。也可以点「添加应用…」选择其他已安装的 App。软件按当前前台 App 自动使用对应映射。只有单独改过的键会覆盖预设里的默认映射。用「恢复默认」撤销覆盖，用「停用按键」让这个键在当前 App 里不执行动作。应用映射随整套预设保存和复制。

## 用信源键切换应用

在 Agent Coding 和看视频的默认映射里，短按遥控器正面右下角的「信源」键会列出 Mac 正在运行的 App。用方向键选中一个，按圆环中间的确定键打开。按返回或再短按一次信源键关闭。也可以把「切换应用」赋给其他遥控器键。

## 飞鼠模式

在 Remote Go 主窗口顶部打开「飞鼠模式」，或按住右下角的信源键 1 秒。开启时屏幕显示「飞鼠模式」。短按方向键微调 Mac 指针，按住加速，松手停止。确定做一次左键点按。侧边音量加减短按滚动一格，按住连续滚动，松手停止。按返回或再次按住信源 1 秒退出，短按信源会退出飞鼠模式并打开应用列表。退出时显示「飞鼠已退出」，随后提示条散成细小粒子。开启系统「减少动态效果」时只显示文字提示。

支持把「切换飞鼠模式」分配给其他可识别的按键。窗口顶部可直接开关。

## 看视频预设

| 遥控器按键 | 默认动作 |
| --- | --- |
| 确定 | 播放／暂停（K） |
| ←／→ | 快退／快进 10 秒（J／L） |
| ↑／↓ | 当播放进度条获得焦点时，调节 YouTube 播放器音量 |
| 音量＋／−、静音 | 调节 Mac 系统音量或静音，音量键可按住连调 |
| 主页 | 短按全屏，长按切换预设 |
| 返回 | Esc，用于退出全屏 |
| YouTube | 在默认浏览器打开 YouTube |
| Netflix | 开关 YouTube 字幕（C，视频需有可用字幕） |
| 信源 | 短按切换应用，长按 1 秒开关飞鼠 |
| 电源 | 单按暂停／恢复改键 |

打开 YouTube 视频后，先点一下播放器，让它接收快捷键。[YouTube 快捷键](https://support.google.com/youtube/answer/7631406?hl=en-GB)

## Agent Coding 预设

短按主页轮换最近三个 Codex 会话。在 Codex 前台时，侧边音量＋往左栏上一项，音量−往下一项。沿左栏的已展开列表移动，到首尾停止。Remote Go 在启用改键时记录能够识别到的最近打开的 Codex 本地会话，只保存会话 ID。记录不足时使用 Codex 的三个最近更新会话位。切换后会尝试聚焦输入框，供圆点语音键继续触发听写。

在 Codex 前台按住音量＋ 1 秒，会看到当前登录 Codex CLI 账户的剩余用量和重置时间。用量浮层几秒后自动关闭，当前对话保留焦点。

在 Grok Bot 前台，短按音量＋切到左栏上一项，音量−切到下一项，到首尾停止。切换后会聚焦输入框。可以在「按应用改键」中选 Grok Bot 改这两个键。

如需在不同 Agent 之间快速切换，可把空闲键映射为「轮换 Codex 和 Claude」，它会尝试聚焦目标 App 的当前会话。信源键的 App 列表也可以切到 WorkBuddy 和豆包工作。

| 遥控器按键 | 动作 |
| --- | --- |
| 主页 | 短按轮换最近三个 Codex 会话并尝试聚焦输入框，长按切换预设 |
| 音量 + | 短按到左栏上一项，按住 1 秒查看 Codex 用量 |
| 音量 − | Codex 左栏下一项 |
| 静音 | Esc |
| ↑／↓／←／→ | 对应的键盘方向键 |
| 选择会话（可映射给任意键） | 在 Codex 或 Claude 里打开会话选择，在选择框里再按一次关闭 |
| YouTube | 打开 Codex 并聚焦对话输入框 |
| Netflix | 打开 Claude 桌面版并聚焦对话输入框 |
| 专用语音键（圆点图标） | 默认长按发送 Fn，可以另设双击快捷键 |
| 确定 | 当前配置发送 Return，可用于 Codex 和 Claude |
| 信源 | 切换 Mac 上正在运行的应用 |
| 电源 | 按一下暂停改键，再按一下恢复。要求 Mac 能收到电源键的蓝牙事件 |

会话选择打开后，用方向上／下移动，按确定进入选中的对话。会话选择只在支持的应用里生效。

关闭窗口后可从菜单栏重新打开。在菜单栏勾选「登录时在菜单栏启动」，登录后会在后台等遥控器连接。30 分钟没有使用遥控器会自动暂停，按电源键恢复。

## 收音来源与验证

Mac 键盘发起听写时接入电脑麦克风，遥控器发起时使用遥控器麦克风。两条路径通过已选的回环麦克风输入听写软件。需要使用其他 App 的麦克风时，可在对应 App 中选择自己的输入设备。

遥控器长按和持续听写的最长会话是 30 分钟。退出 Remote Go 后，要继续用键盘听写，可以在听写软件中选 Mac 内建麦克风。

程序自检覆盖 HID、按键连发、预设迁移、快捷键和 ATVV 解码。安装后可分别用 Mac 键盘和遥控器验证听写，并检查蓝牙断开和重连后是否能恢复。

## 重建和升级

在仓库根目录运行 `./build.sh`，输出到 `dist/Remote Go.app`。从同一位置重新安装或更新后，如果改键失效，可以在系统设置检查辅助功能授权。
